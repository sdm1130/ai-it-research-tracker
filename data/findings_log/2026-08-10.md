## Addendum — 2026-08-14: this run never reached `main` (recovered by hand)

The research above was correct and complete, and the Claude Artifact **was** republished
on 2026-08-10 with this data. But the GitHub Pages mirror was **not**, and sat stale at
2026-08-03 for four days.

**What happened.** The sandbox was checked out on the generated branch
`claude/brave-carson-xx678v`. The run called `publish_pages.py --check-auth`, which
printed `branch : claude/brave-carson-xx678v`. Reading that as the push target, the run
concluded it was under a "branch-push restriction", committed the data files to the
working branch, pushed *that branch*, and then called `publish_pages.py --dry-run` —
which writes a local preview and pushes nothing. It then reported the run as successful.

Nothing in the pipeline contradicted that report, because `--dry-run` exits 0 and
§5b only ever checked the exit code of a command it assumed had been the real one.

**Why 2026-08-03 worked.** Same branch setup — that run simply happened to call the
script for real. This was a behavioural coin-flip, not a broken configuration, so it
would have recurred at random.

**Recovery.** `main` was fast-forwarded to `aa9b028` (clean, no conflicts — nothing was
lost), rebuilt, and republished.

**Fixes, so this cannot silently recur:**

1. `--check-auth` now prints `PUSH TARGET : main (this script always pushes HEAD:main)`
   and, when on another branch, states explicitly that this is expected in a cloud run
   and is not a restriction.
2. `--dry-run` now prints `*** THE PUBLIC MIRROR WAS NOT UPDATED. ***`
3. New `publish_pages.py --verify` compares the live `origin/main:index.html` against the
   page the checkout builds, and exits non-zero on drift. §5b now requires it as the last
   step of every run — the mirror may only be reported as updated if it exits 0.
4. `AGENT_PROMPT.md` §5b documents the branch situation directly, including this incident.

The lesson generalised: the pipeline was verifying *that a command was issued*, never
*that the world changed*. `--verify` checks the world.
